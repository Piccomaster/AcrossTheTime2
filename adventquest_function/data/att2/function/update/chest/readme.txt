Chest Marker Entity Update Instructions:

Enter "function att2:update/chest/start" to begin the update.

Enter "function att2:update/chest/reset" to stop the update and reset the progress.

Script Usage:
After starting the script in VSCode, input the file path to the Excel spreadsheet containing the chest coordinates.
###Use the Google Sheets with chest data
The script will then automatically generate all the summon commands and the corresponding start.mcfunction file.
