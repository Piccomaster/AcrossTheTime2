# Running Instructions

## Execute Main File
- Run the "main" file in VSCode.

## Dependency Issues
If you encounter issues with dependency libraries:
- **Option 1**: Run the "dependency library installation" script for automatic installation.
- **Option 2**: Install the required libraries manually.

## Usage
After running the main file:
1. Select the corresponding function.
2. Enter the chunk folder or chunk file path.

### Example Path Formats:
- Folder path:  
  `D:\minecraft.minecraft\versions\1.21.10\saves\ATT2 1.21.5 6.0.4 playing\region`
- File path:  
  `D:\minecraft\.minecraft\versions\1.21.10\saves\ATT2 1.21.5 6.0.4 playing\region\r.1.0.mca`
